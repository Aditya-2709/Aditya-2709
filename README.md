## ● Projects

### FixQue &nbsp;![Working](https://img.shields.io/badge/status-working-7DFFA8?style=flat-square&labelColor=040705)

> An integrated hospital and clinic platform for **appointment booking, patient management, medical records, prescriptions and billing**, connecting patients, hospitals, doctors and medical stores in one system.

| Portal | What it does |
| :-- | :-- |
| **Patient** | Registers or logs in, opens a personal dashboard, discovers hospitals and clinics, checks open time slots, books an appointment and pays. |
| **Hospital / Clinic** | Registers on a dedicated page and manages all upcoming, completed and cancelled appointments. Each one can be confirmed, cancelled or rescheduled. |
| **Doctor** | Sees the hospital's patients (name, age, earlier health records), adds a new consultation record with a prescription, generates a consultation bill and sends the prescription to a chosen medical store. |
| **Medical store** | Receives only the medicines prescribed for that patient, never their full history, and creates a separate bill for those medicines. |

<details>
<summary><b>How the patient journey flows</b></summary>

<br/>

```
Patient signs up / logs in
        ↓
Picks a hospital or clinic  →  checks time slots
        ↓
Books appointment  →  hospital confirms / cancels / reschedules
        ↓
Doctor consults  →  adds health record + prescription
        ↓                          ↓
Consultation bill (hospital)   Prescription sent to medical store
                                   ↓
                           Medicine bill (store only sees medicines)
        ↓
Patient pays by UPI or card
```

Consultation charges and pharmacy charges are billed **separately**, so each can be handled on its own.

</details>

### Algothix OS (ALX) &nbsp;![Completed](https://img.shields.io/badge/status-completed-EEF4EE?style=flat-square&labelColor=040705)

> A lightweight, **Debian-based Linux distribution made for programmers**. Terminal-first, multi-user, and tuned to run smoothly on old laptops with **2 to 4 GB of RAM** and a spinning hard drive.

| Feature | Details |
| :-- | :-- |
| **Terminal-first** | The command line is the main way to work, so the system stays fast and out of the way. |
| **Multi-user** | Several people can have their own accounts and workspaces on one machine. |
| **Built for old hardware** | Runs well on 2 to 4 GB of RAM with a hard drive, giving older laptops a second life. |
| **Connected workspace** | Several ALX machines can work together like one workspace. |

[![Visit ALX website](https://img.shields.io/badge/Visit-ALX%20website-7DFFA8?style=for-the-badge&labelColor=040705)](https://algothixos.vercel.app)
